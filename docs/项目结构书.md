# 📁 项目结构书

> 版本：v3.3.1 · 更新日期：2026-08-17

## 总览

```
drink_rag_robot/
├── backend/                    # ★ FastAPI 后端（核心）
├── frontend/                   # ★ Vue 3 前端
├── data/                       # 知识库与运行时数据
├── docs/                       # 全套文档
├── scripts/                    # 运维/测试脚本
├── .env.example                # 配置模板（复制为 .env 使用）
├── .gitignore                  # Git 忽略规则
├── README.md                   # 项目门面
├── requirements.txt            # 根依赖（转发至 backend）
└── start.py                    # 一键启动脚本
```

## 后端 backend/

```
backend/
├── main.py                     # ★ 应用入口
│     · 应用工厂 + 生命周期（建库 / 后台预热 RAG）
│     · CORS / 访问日志中间件
│     · 挂载路由 + 托管前端 dist + SPA 回退
│
├── api/                        # —— 路由层（只做 HTTP 契约与错误映射）——
│   ├── chat.py                 # POST /api/chat（普通+SSE流式）、历史、清空
│   ├── knowledge.py            # 文档上传/列表/详情/删除 + 检索调试 + 统计
│   └── system.py               # 健康检查 / 综合状态 / 按天统计 / 配置预览
│
├── core/                       # —— 基础设施层 ——
│   ├── config.py               # ★ 全局配置中心（pydantic + .env + 环境变量注入）
│   ├── database.py             # ★ SQLite 持久化（WAL）：
│   │                           #   conversations / knowledge_docs / knowledge_chunks / stats_daily
│   └── logging.py              # 统一日志（控制台 + 滚动文件，UTF-8 兼容）
│
├── models/                     # —— Pydantic 数据模型 ——
│   └── schemas.py              # ChatRequest/ChatResponse/CitationItem/DocInfo/统计模型等
│
├── rag/                        # ★ —— 高级 RAG 引擎（算法核心） ——
│   ├── embeddings.py           # bge 中文语义嵌入：指令前缀、批量、LRU 缓存、GPU
│   ├── vector_store.py         # FAISS IndexFlatIP：向量/元数据映射、软删除、重建
│   ├── sparse_retriever.py     # 自研 BM25：jieba + numpy 向量化打分
│   ├── hybrid_retriever.py     # 双路召回 + RRF/加权融合 + 去重标记
│   ├── reranker.py             # 交叉编码器精排（bge-reranker-base），失败降级
│   ├── chunker.py              # 智能分块：饮料块 / 句子边界递归 + overlap
│   ├── document_loader.py      # 多格式解析：txt/md/csv/json/pdf/docx
│   └── engine.py               # ★ RAG 引擎总控：建索引、入库、删除、检索、统计
│
├── services/                   # —— 业务服务层 ——
│   ├── llm_service.py          # 千问调用：openai SDK + OpenAI 兼容协议、SSE 流式、重试、查询改写
│   ├── chat_service.py         # 对话编排：历史、改写、检索、Prompt、落库、统计
│   ├── knowledge_service.py    # 知识库业务：上传校验、删除、搜索、统计
│   └── stats_service.py        # 系统状态与仪表盘数据聚合
│
├── tests/                      # —— 单元测试 ——
│   ├── __init__.py
│   └── test_rag.py             # 分块 + BM25 共 10 个用例（离线可跑）
│
└── requirements.txt            # 后端依赖清单
```

## 前端 frontend/

```
frontend/
├── index.html                  # SPA 入口（FontAwesome CDN、favicon）
├── package.json                # 依赖与脚本（dev/build/preview）
├── vite.config.js              # Vite 配置：@别名、/api 代理、构建输出
├── dist/                       # ★ 构建产物（由后端 FastAPI 托管，gitignore）
└── src/
    ├── main.js                 # 入口：挂载 App、Pinia、Router、主题初始化
    ├── App.vue                 # 应用外壳：侧栏导航 + 路由视图 + 主题切换
    ├── router/index.js         # 路由表（chat / knowledge / dashboard）
    ├── stores/                 # —— Pinia 状态 ——
    │   ├── chat.js             # 会话、流式发送、历史
    │   ├── knowledge.js        # 文档列表、上传、删除
    │   └── system.js           # 系统状态、按天统计
    ├── api/                    # —— 请求封装 ——
    │   ├── request.js          # Axios 实例 + 错误拦截（含上传实例）
    │   ├── chat.js             # SSE 流式解析（fetch + 事件分派）
    │   ├── knowledge.js        # 知识库接口
    │   └── system.js           # 系统接口
    ├── components/             # —— 通用组件 ——
    │   ├── AnimatedBackground.vue  # 粒子连线 + 极光动效背景
    │   └── MessageItem.vue         # 消息气泡（Markdown/来源/复制/打字动画）
    ├── views/                  # —— 页面 ——
    │   ├── ChatView.vue        # 智能问答页（流式/欢迎页/快捷提问）
    │   ├── KnowledgeView.vue   # 知识库管理页（上传/搜索/详情抽屉）
    │   └── DashboardView.vue   # 系统监控页（ECharts 趋势/分类图/RAG配置）
    ├── styles/
    │   └── base.css            # ★ 设计系统（CSS 变量、玻璃拟态、双主题、Markdown 样式）
    └── utils/
        ├── format.js           # 时间/大小/文件类型格式化
        └── markdown.js         # Markdown 渲染（安全模式 + 代码块增强）
```
