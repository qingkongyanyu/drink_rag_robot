### 🐛 修复：SSE 流式输出失效（核心 Bug）
- **根因**：后端 SSE 事件把事件类型放在 `event:` 行，`data:` 载荷中无 `type` 字段；而前端解析器只读取 `data:` 行并按 `data.type` 分发，导致 `meta / delta / done / error` 全部无法匹配，流式输出时好时坏（“要么能输出要么不能”）。
- **修复**：
  - 前端 `api/chat.js` 重写 SSE 解析：同时解析 `event:` 行与 `data.type`，按「事件名 || data.type」统一分发（兼容两种 SSE 形态）；
  - 后端 `api/chat.py` `_sse_event` 在 `data` 载荷中同步写入 `type` 字段（双保险，向后兼容）。

### 🚀 重大变更：Flask → FastAPI 全面重构 + 高级 RAG + Vue3 前端

#### 后端（FastAPI）
- **框架替换**：Flask → FastAPI（异步、Pydantic 校验、原生 OpenAPI 文档 `/api/docs`）
- **高级 RAG 引擎**：
  - 新增 `bge-small-zh` 中文语义向量检索（512 维，指令前缀，LRU 缓存）

  - 新增 **混合检索 + RRF 融合**（可切换加权融合）
  - 新增 **交叉编码器重排**（bge-reranker-base，按需启用、失败自动降级）
  - 新增 **查询改写**（多轮指代消解）
  - 新增智能**分块**（句子边界 + overlap）与多格式**文档解析**（txt/md/csv/json/pdf/docx）
- **知识库管理**：上传/列表/详情/删除/检索调试/统计 全套 API
- **LLM 服务**：OpenAI 兼容协议、**SSE 流式输出**、重试与错误分类

- **配置中心**：.env + 环境变量注入，密钥与参数全部外置
- **健壮性**：各环节失败自动降级（重排/改写/检索）
