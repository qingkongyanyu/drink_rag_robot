## 6. 已知限制与后续计划

| 限制 | 说明 | 计划 |
|------|------|------|
| 单 worker | 索引在进程内，多 worker 会重复加载 | 部署用单 worker / 未来接向量数据库 |
| 重排默认关闭 | 需下载 ~800MB 模型 | 下载后 `RAG_USE_RERANKER=true` 即启用 |
| 图片型 PDF | 无法直接提取文本 | 建议 OCR 后上传 |
| SQLite 并发 | 中小规模足够 | 可平滑迁移 PostgreSQL |
