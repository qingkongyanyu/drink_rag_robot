# 📖 用户使用手册

> 面向系统使用者（无需懂代码）。版本：v3.3.1 · 更新日期：2026-08-17

## 1. 快速上手

1. 启动系统后，在浏览器打开 http://127.0.0.1:8002
2. 在下方输入框输入饮料健康问题，按 Enter 或点击右侧绿色发送按钮
3. 助手会**流式打字**给出回答（**微信风格**：机器人回答在左侧气泡、你的消息在右侧绿色气泡，头像自动区分），回答下方可展开**参考来源**核对依据
4. 若页面样式异常或流式不出字，请先按 **Ctrl+F5 强制刷新**（清除缓存）

## 2. 智能问答

### 你可以问什么？

- 「可口可乐含糖量高吗？糖尿病人能喝吗？」
- 「虚寒体质适合喝什么饮料？」
- 「夏天有什么清爽低卡的饮料推荐？」
- 「红牛长期喝有什么副作用？」
- 「纯牛奶适合什么人群？」

### 小技巧

| 操作 | 说明 |
|------|------|
| Enter | 发送 |
| Shift + Enter | 换行 |
| 🕐 记忆按钮 | 开关多轮上下文（开：助手记得上文） |
| ❝ 引用按钮 | 开关回答的来源标注 |
| 🗑 清空 | 清空当前会话记录 |

## 3. 知识库管理

进入左侧「知识库管理」：

### 3.1 上传知识

- 点击上传区或将文件**拖拽**进来；
- 支持格式：`.txt .md .csv .json .pdf .docx`；
- 可填「分类」便于组织（如"营养资料""客户产品"）；
- 点击「上传」后自动完成：解析 → 分块 → 建立索引，即可被检索。

### 3.2 管理文档

- 每张文档卡片显示：类型、大小、分块数、分类、状态；
- **查看**：弹出抽屉展示每个知识块（含向量编号）；
- **删除**：立即从检索库移除。

### 3.3 检索调试

「检索调试」页输入任意问题，可看到：

- 命中哪些知识块、相似度分数；
- 召回方式：**混合**（语义+关键词都命中）/ **语义** / **关键词**；
- 用于验证新上传知识是否生效。

## 4. 系统监控

进入左侧「系统监控」查看：

- **运行状态**：RAG 引擎是否就绪、API Key 是否配置、运行时长、推理设备（CPU/GPU）；
- **核心指标**：文档数、知识分块数、向量条数、今日问答量、会话数；
- **趋势图表**：近 14 天问答量与上传量；
- **分类分布**：各类知识的占比饼图；
- **RAG 管道配置**：当前检索参数一览。

## 5. 常见问题

<details>
<summary><b>助手回答"知识库中暂无相关记录"？</b></summary>
说明这个问题在已上传知识里没有足够依据。可以：换个关键词再问；上传相关知识文档后再问。
</details>

<details>
<summary><b>上传 PDF 后搜不到内容？</b></summary>
可能是扫描件/图片型 PDF（只有图没有文字）。请使用文本型 PDF，或转成 txt/md 后上传。
</details>

<details>
<summary><b>回答很慢？</b></summary>
流式回答本身是逐字出现的，耐心等待即可；首次提问因模型预热会稍慢，之后会更快。
</details>

<details>
<summary><b>怎么切换深/浅色主题？</b></summary>
点击侧栏底部的 ☀/🌙 按钮即可切换，选择会被记住。
</details>

## 6. 隐私提示

- 问答记录与上传文档保存在本地 `data/` 目录；
- 上传内容仅用于本地检索与回答生成，不会共享给第三方（请勿上传敏感个人信息）。
